# Working on Faithful Repertoire

Read README.md, DESIGN.md and REQUESTS.md before making changes. Track every user
request in REQUESTS.md with completed work, checks and precise remaining blockers.
Resume pending requests after interruptions and preserve earlier requirements.
Use the existing checkout; do not create worktrees unless asked. Preserve all
personal data and existing local changes. Human users choose songs, approvals and
service plans. Never invent song metadata or replace missing evidence with scores.
Tests and local Pages builds are separate from pushing or publishing the website.
Run `npm run code:count` at the start and completion of each task. Include the
source/check total in the final update so the running count stays visible.
CODE-STATS.md refreshes automatically after site builds; exclude generated docs
copies from the main total. Codex's native top-right UI is not configurable here.
